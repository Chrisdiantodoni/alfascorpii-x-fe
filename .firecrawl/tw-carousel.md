Alternatively, use `data-twe-slide-to` to pass a raw\nslide index to the carousel `data-twe-slide-to=\"2\"`, which\nshifts the slide position to a particular index beginning with\n`0`.\n\n\nThe `data-twe-carousel-init` and\n`data-twe-ride=\"carousel\"` attributes are used to mark a\ncarousel as animating starting at page load. If you don’t use these\nattributes to initialize your carousel, you have to initialize it\nyourself.\n**It cannot be used in combination with (redundant and unnecessary)**\n**explicit JavaScript initialization of the same carousel.**\n\nShow code\n\n\n- [HTML](https://tw-elements.com/docs/standard/components/carousel/#mdb_5aa800e5259d061fe2233c7e4cffd294db85098c)\n\n```html\n\n```\n\nCopy\n\n#### Via JavaScript\n\nYou can access an instance from your Javascript code, by using the\n`getInstance` static\nmethod of the Carousel class - it allows making use of all the public\nmethods listed in the\n[Methods](https://tw-elements.com/docs/standard/components/carousel/#api-section-methods) section.\n\n\nShow code\n\n\n- [javascript](https://tw-elements.com/docs/standard/components/carousel/#mdb_cef6824f419839bd49110b0cbaa9a32625f6eff3)\n- [javascript](https://tw-elements.com/docs/standard/components/carousel/#mdb_492484e5bb523ab8811989c3778faf05a7aa3987)\n\nESUMD\n\n```js\n\n```\n\nCopy\n\n```js\n\n```\n\nCopy\n\n* * *\n\n## Options\n\nOptions can be passed via data attributes or JavaScript. For data\nattributes, append the option name to `data-twe-`, as in\n`data-twe-interval=\"4000\"`.\n\n\n| Name | Type | Default | Description |\n| --- | --- | --- | --- |\n| `interval` | number | `5000` | The amount of time to delay between automatically cycling an<br> item. If false, carousel will not automatically cycle. |\n| `keyboard` | boolean | `true` | Whether the carousel should react to keyboard events. |\n| `pause` | string \\| boolean | `\"hover\"` | If set to `\"hover\"`, pauses the cycling of the<br>carousel on `mouseenter` and resumes the<br>cycling of the carousel on `mouseleave`. If set<br>to false, hovering over the carousel won't pause it.<br> <br>On touch-enabled devices, when set to<br>`\"hover\"`, cycling will pause on<br>`touchend` (once the user finished interacting<br>with the carousel) for two intervals, before automatically<br>resuming. Note that this is in addition to the above mouse<br>behavior. |\n| `ride` | string \\| boolean | `false` | If set to `true`, autoplays the carousel after<br> the user manually cycles the first item.
